## Declared defaults and findings
- **Declared default (contract silent):** a cell whose fractions are all ≤ 0 (sum not > 0) becomes pure hydrogen
  (x_H = 1, the rest 0). Cheap to reverse: one branch in floors.wgsl and the test's oracle. A §2.7 or §2.5 amendment
  should state it, so the CPU twin matches.
- NaN fractions: WGSL's `max(NaN, 0)` is implementation-defined; not handled here — P9's non-finite guard (§3.3, exit 5)
  is the catch. Denormal sums may flush to zero on a GPU and give hydrogen where the f64 twin would not.
- R13 asks each pass's CPU f64 twin before its GPU shader: the twin of this pass in sr-physics `reference` is not in
  this block's Deliver; the test carries an inline f64 oracle. Flagged to M0-T19, which completes P8.
- `State::readback` blocks on `device.poll` — native and headless only; a web readback (if one is ever needed) maps
  asynchronously.
- Size: 592 new lines in the five new files, plus ≈ 50 lines of edits (gpu.sh, main.rs, lib.rs, verify.json) — at the
  600-line ceiling, not over it in new code.
- docs/agent/testing.md's row for `state` and gpu.sh's `physics` argument: left to M0-T9 (R11: the lot's docs block
