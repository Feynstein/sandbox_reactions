## What exists now
- **shaders/heat.wgsl.** `heat_round`'s `CELL_BUILD`: on the V-cycle (`parity.mg`) the first iterate is T⁰ + krylov[KR_S] × Δt_n, T⁰ outside
  [T⁰/2, 2 T⁰] or not finite, then `max(·, T_floor)`; on Jacobi T⁰, the code as it was. `heat_apply` (now binding 15, krylov) writes each box
  cell's rate (T − T⁰)/Δt_n (`machine.rec[1].dt`) into krylov's first s plane; 0 off the gas and when the step did not run (`stepped` 0). No
  round reads that plane before writing it (Chronopoulos–Gear: a solve's first round reads no s), so it is free between steps. A cell
  outside the box keeps the rate it had when last inside it (only a guess, bounded by the factor-2 fallback; deterministic, and dumped).
- **step/heat.rs.** krylov gains COPY_SRC | COPY_DST; `Heat` keeps it, the state's upload count (`State::uploads`, an `Arc<AtomicU64>`
  bumped by every `State::upload`) and the count last seen. `Heat::forget_rate`, called first in `Step::encode_step` (step/mod.rs, the one
  place every bare step and frame step is recorded), `clear_buffer`s the plane when the count moved. `Step::heat_rate` reads the plane
  (a one-plane staging copy); `Step::set_heat_rate` writes it (zeros for none) and marks the uploads seen.
- **dump.rs.** `Dump::rate`; the header's `resume.rate` (always written; optional when read — absent reads false, so every older dump
  still loads); the plane after F's two. Refused: the flag set with no plane, cleared over one, set without F (`flux` false), a rate of
  another length in `load_dump`. `dump_state` reads it; `load_dump` writes it after the upload (zeros when the dump holds none).
  headless.rs's `twin_dump` sets `rate: None`. calibrate's checkpoint goes through `dump_state` / `load_dump`: the life's
  `checkpoint/s_1400.bin` reads `resume.rate: true`, 17 planes.
- **Tests.** dump.rs: `a_warm_life_cut_by_a_dump_and_continued_is_the_unbroken_one_byte_for_byte_ten_steps_on` (sun_disk 30 + 10 against a
  dump at 30 loaded and run 10; the 17th plane read by hand; the control without the rate must differ) and the rate's refusals in
  `a_wrong_magic_or_a_header_off_the_contract_is_refused`. Plants: `tests/plants/warm-no-reset.patch` (heat_implicit),
  `tests/plants/warm-rate-not-dumped.patch` (dump). verify.json: dump expects 12; both plants registered.
