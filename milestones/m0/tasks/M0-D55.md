## Each red: cause and fix
Two patterns, as the block's Deliver set them:
- **Pin.** An oracle that grades a law at a stated state pins the constants it was written for through `Physics::with`
  (G-COLL's pattern), never a looser tolerance.
- **Read the shipped values.** An oracle that grades the shipped values reads §0.5 [M0-D50]'s, or builds its edge
  cases from today's neighbours.
