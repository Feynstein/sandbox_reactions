# M0-T21 — The active box (detail)

Box: win-laptop `Laser2025-20`, adapter NVIDIA GeForce RTX 4080 Laptop GPU (Vulkan), 2026-10-10. Model: claude-opus-5-5,
level high (`rung_record.py now`).

## What exists now
- `crates/sr-engine/src/step/boxfit.rs` (new): `BoxFit` — the box record (`ActiveBox`: x0, y0, w, h, fft_w, fft_h,
  from_step, fits; UNIFORM | STORAGE), the passes' indirect sizes (`box.args`: 8 × 8 tiles at `ARGS_TILES` = 0, 256-cell
  workgroups at `ARGS_CELLS` = 12), P0's gate sizes (`box.gate`), the edit flag (`box.flags`, one u32), the scan partials;
  `BoxMode::{Fit, WholeWorld}` (the whole-world switch); `BoxReport` read back for tests only; `REFIT_EVERY` = 16.
- `shaders/reduce.wgsl`: `box_cells` (256 cells of the whole world per workgroup, Σ ≥ Σ_vac → (x, y, x + 1, y + 1),
  halved as min/min/max/max), `box_fit` (one workgroup over the partials in index order; grow by `MARGIN` = 8, clamp, round
  out to 8 — clamping first is the same box since 0 and the world are multiples of 8; writes the record, `box.args`, the FFT
  sizes, `from_step` = the dt record's `steps`, clears the flag), `box_gate` (P0: scan and fit sized to the whole world
  when the flag is set, zero otherwise). `dt_cells` now walks the box's cells row-major within the box and is dispatched
  indirectly; `dt_partials` walks ⌈w·h/256⌉ partials. The guard still scans the whole world.
- `shaders/floors.wgsl`: `floor_cells` and `renormalise_species` run over the box's tiles from its origin, indirect.
- `step/mod.rs`: `Size::{Fixed, Indirect}` replaces `Dispatch::workgroups`; `Step::with_box(…, BoxMode)` (`Step::new` = Fit);
  `box_labels`, `box_sized`, `read_box`, `box_edit_flag`. Encode order: before step 0 — box fit, then Δt reduction; P0 — the
  edits (none yet), then `box_gate`, `box_cells`, `box_fit` (gated); P9 — Δt, guard every 64th, box re-fit every 16th.
- `tests/gpu/box.rs` (module `r#box` — `box` is a reserved word in Rust), 6 cases; scope `box` in verify.json;
  plant `tests/plants/margin-zero.patch`; docs/agent/testing.md row.

## Defaults taken (cheap to reverse)
- Empty box (an all-vacuum world): w = h = 0, every box-sized dispatch is zero workgroups, Δt_{n+1} is the largest finite
  f32 (no cell bounds it). The whole-world reduction used to give the vacuum floor's Δt.
- The re-fit's scan reads the whole world (P0 must find an edit anywhere; P9 could scan only the box — 1 dispatch in 16).
- The non-finite guard scans the whole world (every 64 steps), not the box.
- P0 records `box_gate` + two zero-sized indirect dispatches every step, edits or not.
- Cells outside the box are never touched: an uploaded vacuum cell with Σ = 0 stays 0 (P8 floors only inside the box).
