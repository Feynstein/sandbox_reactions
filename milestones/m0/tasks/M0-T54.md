# M0-T54 — neutrino heating on the GPU (P7)

Box: linux-pc (laserax-ai), RTX 5090 (physics adapter, R12). model=claude-sonnet-5-5 level=high (rung_record now; matches the heading).

## Built
- `crates/sr-engine/shaders/nuheat.wgsl` (appended to fft.wgsl, as grav.wgsl) and `crates/sr-engine/src/step/nuheat.rs`: P7 =
  `nu_tiles` (box tiles, each tile's ΣS_ν by a fixed tree) → `nu_gate` (one workgroup: the tiles' sum in a fixed order; writes the
  sizes of the rest into P7's own buffer — all 0 when ΣS_ν = 0) → `conv_rows` / `nu_columns` / `conv_rows_inverse` (reach = S_ν ∗ K_ν
  on K̂'s real quarter per padded size, the machinery of P2) → `nu_deposit` (D = Σ·reach, 0 where X_n ≥ 0.5, ≥ 0; tile sums) →
  `nu_share` (ΣD in a fixed order; scale = f_dep ΣS_ν/ΣD, 0 when ΣD = 0) → `nu_apply` (E += scale·D·Δt_n, booked
  `neutrino_deposited` at the cell, only where q > 0) → `nu_close` (sizes back to 0). No atomic.
- `Step::with_neutrino_heating` (with_sinks delegates with None), `Step::read_nuheat` → `NuHeatReport { steps, opened, ran, emitted,
  total, scale }`; `grav::spectra_of(width, height, kernel)` (spectra delegates, P2 unchanged); `reference::nuheat::kernel` made pub.
- tests/gpu/nuheat.rs: 8 GPU cases (scope nu_heat 7 → 15), plants `nuheat-gpu-no-cap` (nu_share counts f_dep twice) and
  `nuheat-gpu-always-dispatch` (the gate opens at ΣS_ν ≥ 0).

## Declared readings (cheap to reverse)
- The carried flag asked for a third indirect buffer in latch.wgsl's zero_sizes/latch_end and a widened assert. I used `Size::Chained`
  instead (P5's precedent: "the latch reaches the chain through the fixed-size dispatch that opens it"): P7's sizes are written by
  `nu_gate` and zeroed by `nu_close`, both fixed-size, so a stopped step runs neither and the sizes stay 0; latch.rs / latch.wgsl are
  untouched and the assert still reads exactly two indirect buffers. Proven by `gpu_a_stopped_frame_runs_no_p7_after_it`.
- ΣS_ν is summed over the box, not the world (S_ν lives in non-vacuum cells, the box covers them); a hand-made S_ν outside the box is ignored.
- Cold pressure is off in the GPU worlds (the four K's 0): the hand-made E = Σ is below a cold electron gas's energy, and P8 would raise it.
- "No dispatch ... read from the timing report": the timing report holds a cost per pass, not a dispatch count, so the proof is the
  GPU's own `ran` (nu_share's stamp) and the state/booking bit-for-bit a P7-less step's; the timing is a second witness (P7 0.015 ms
  silent against 0.086 ms with a star at 512 × 512, RTX 5090) and reads NOT RUN (no timestamp-query) where the device lacks it.
