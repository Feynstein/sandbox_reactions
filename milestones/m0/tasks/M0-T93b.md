# M0-T93b — the cell inspector (detail)

Ran on linux-pc (laserax-ai), claude-sonnet-5-5, high.

- Flow each frame (`Sim::frame` → `inspect_frame`): poll the Inspector (never blocks) → `Asker::answered` → `Reader::read` into `Sim.reading`;
  then `Asker::next(hover)` → one `Inspector::inspect` while none is in flight. `set_hover` (end of the central panel) holds the pointer's cell;
  leaving the world drops the reading. The panel shows a reply 1–2 frames old at most.
- `capture`'s `hover` is `SandboxApp.scripted_hover`: it wins over the real pointer (Xvfb has one at the window's middle).
- Mix cut: a share counts at 0.5 % × (1 − 10⁻⁶) because an f32 0.005 reads 0.4999999.
- Mach hand value in the test uses Σ = 10⁻⁵: at 10⁻³ the electron pressure is already 0.5 % of Π.
- Logs: logs/M0-T93b.*.log (scopes, red-arms), logs/M0-T93b.hover_frames.log (the 120-frame hover, synthetic).
- Owed: win-laptop run of `ui_inspect`, `capture` (R15).
