## The scheme (decisions the contract leaves to the builder)
- **Conductance form.** A face's flux is F = −K_f (T_b − T_a), K_f = c_sb λ(R) a_r (T_a + T_b)(T_a² + T_b²)/(κΣ)_f + k_cond.
  a_r(T_b⁴ − T_a⁴)/(T_b − T_a) is taken as the product, so there is no 0/0 at ΔT = 0. κΣ and a_r T⁴ inside R are the arithmetic means
  of the two cells'; |F| = c_sb λR · a_r T⁴_face ≤ c_sb a_r T⁴ of the hotter side because λR < 1.
- **Frozen coefficients.** K_f is computed once from the start-of-pass temperatures; the stages advance the linear system
  C dT/dt = Σ_f K_f (T_nb − T) with C = Σ/μ. Δt_p = 1/max_cells(Σ_f K_f / C) — the contract's 0.5/max(χ/Δx² + χ/Δy²) where χ is uniform
  (4χ = Σ_f K/C), Gershgorin's bound where it is not.
- **RKL2 coefficients** (Meyer et al. 2012): b_0 = b_1 = b_2 = 1/3, b_j = (j² + j − 2)/(2j(j + 1)); w_1 = 4/(s² + s − 2);
  μ̃_1 = b_1 w_1; μ_j = (2j − 1)/j · b_j/b_{j−1}, ν_j = −(j − 1)/j · b_j/b_{j−2}, μ̃_j = μ_j w_1, γ̃_j = −a_{j−1} μ̃_j. My first draft had
  `s² + s − 4` in w_1; it passed the stability check and G-HEAT1 to 1 % but not the shape (peak 0.528 against 0.4) — the stability polynomial was
  checked offline afterwards: |P| ≤ 1 on [−(s² + s − 2)/2, 0], P′(0) = 1, P″(0)/2 = 1/2 for s = 2, 3, 5, 14.
- **Light leaving.** A vacuum cell (Σ < Σ_vac) or the ghost past the world's edge is the floor state (Σ_floor, T_floor, the gas side's κ and
  μ). The vacuum cell is not updated. What the gas loses through such faces is `radiated`, carried by the same RKL2 recursion as the
  temperatures (R_j = μ_j R_{j−1} + ν_j R_{j−2} + μ̃_j Δt out(Y_{j−1}) + γ̃_j Δt out(Y_0)), per emitting cell, so it equals the grid's loss to
  rounding. Edge mode plays no part (D1).
- **F kept** = the start-of-pass face fluxes (`Pass::flux`); `Flux::cells()` is the cell-centred pair P4 will read (M0-T43).
- **Test flags.** `constant_diffusivity` χ: K_f = χ · (C_a + C_b)/2. `flux_limiter` false: λ ≡ 1/3. `pin_temperature` (the contract names
  the key and nothing more — a default taken, cheap to reverse): the pass leaves the planes alone, books nothing, still keeps F.
- **Floor.** A cell reads T from E floored at T_floor (`Eos::thermal`, as P4 does); the pass writes E += C (Y_s − Y_0), so a stage that ends
  below T_floor is raised by the *next* pass's read and by P8's booking, not by P5.
