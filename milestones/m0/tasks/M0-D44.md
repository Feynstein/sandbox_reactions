# M0-D44 — P4's NaN beside a sink's hole

Box: linux-pc (laserax-ai), RTX 5090 (the physics adapter), 2026-10-15. Model: claude-opus-5-5, level high
(`rung_record.py now`).

## Measured source
A temporary probe (in sink.rs, removed) replayed M0-T51's route: the fall case's rig 31 steps, the state and sinks
read back, one P2 + P3 step (no P4) from them, then the f32 MC slope of Σ over every gas cell (vacuum cells read as
Σ_floor = 1e-8, as `read_cell` does) and one P2 + P4 step from that state.

- Face Σ ≤ 0 at exactly two cells, each one of M0-T51's NaN pairs:
  - (31, 30): Σ 0.2760, x row 1.116 | 1e-8 (the hole (32, 30)) → x+ face Σ **0.0**
  - (34, 33): Σ 0.2606, x row 1e-8 (the hole (33, 33)) | 1.066 → x− face Σ **0.0**
- P2 + P4 from that state: `NonFinite { step: 0, x: 31, y: 30, channel: "sigma" }` (M0-T51's reading).

Mechanism: MC's slope is 2|c − n| when the far neighbour is ≥ 4 × the cell (½(a + b) ≥ 2|a|). In f32,
c − n rounds to c when n = 1e-8 is under half of c's ulp (≈ 1.5e-8 at 0.28), so the face c − ½·2(c − n) is exactly 0.
`cons` then divides by Σ = 0 (ε_th = Π/0), E is NaN, the cell's Hancock delta is NaN on every face, `evolved` falls back
to the unevolved face (Σ 0, E NaN), and HLL on it (c² = 2Π/0) writes NaN into both cells across that face. The f64
twin's face is n = 1e-8: finite.

## Fix (hydro.wgsl only; the twin unchanged)
`bracketed`: each face state's Σ clamped between its cell's and the neighbour's on that side. MC already keeps it there
in exact arithmetic, so this is the twin's scheme with f32's round-off taken out. Only Σ is bracketed: Π's face rounds to
≥ 0, and Π = 0 is finite (c = 0, ε_th floored). Face Σ is now ≥ min(cell, neighbour) ≥ Σ_floor > 0.

Before the fix: the probe above, and the case's own failure (`step 31: grid + sink mass NaN against 3600`, M0-T51).
After: P2 + P4 from the same state finite, and the 40-step fall holding grid + sink mass to 1e-6 each step (the sink
2014.1426 after 40).
