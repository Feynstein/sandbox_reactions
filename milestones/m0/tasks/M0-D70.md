## §1.9.2 — the rulings and the build
- «Its own object (Recommended)»: a sink no block of the summary holds (outside the box, which follows the gas alone, §1.3.3; an
  empty box) is an object of its own: M its mass, gas 0, c the sink, R half a block, τ_dyn √(R³/GM), L 0, the centre values 0 (no
  block) — §1.9.3's first row makes it black_hole. A wisp under 1 % of the Sun-like mass, as gas is.
- «Share by sink (Recommended)»: a pair shares per common block the lesser gas mass (sinks no longer in the block weights) plus, per
  sink both frames hold, the lesser of its two masses. Matching: each previous sink, carried on by its velocity over the frame's sim
  time, goes to the sink of this frame nearest that point within max(r_acc(old), r_acc(new)), r_acc = max(2 cells, 2GM/c_sb²) (§2.6;
  `TrackerConfig` now reads c_sb). Declared choices: the match runs from each previous sink (so a merged sink gathers both — the
  heavier object's id survives through the 25 %/largest-shared rule), ties by the lower slot; a snapshot without each object's sinks
  is refused (as [M0-D78]'s x_h_max).

  next frame — by block it shares only the gas, ≤ 1,880 < 25 % × 30,787 = 7,697, so a fresh id; by sink it shares 1,880 + 28,907.
