## Defaults taken (cheap to reverse) — §2.12.1 does not settle them
1. Object `x`, `y` are points in cell units, cell (i, j) covers [i, i+1) × [j, j+1), sampled at its centre — so
   `preset` at (300, 200) is today's centred disk bit for bit.
2. Overlapping objects add (Σ, momentum, energy, each species' mass; X by mass). Each object's ε_cold is taken at its
   own Σ, so an overlap's cold energy is approximate (P8 recomputes ε_th from E anyway).
3. `--world` that differs from the scene's world shifts the objects by half the size difference (kept about the
   centre). Without it, a 600 × 400 scene at `--world 256x256` would put the disk off the world.
4. Required: `version` (1), `world.width/height`, `objects`; each object's position/size keys, exactly one of
   `t`/`pressure`, `composition` (element keys, ≥ 0, summing to 1 ± 1e-6). Optional with game defaults: `world.edge`
   (leave), `slowdown` (true), every switch (on), `test` (pin false, constant_diffusivity null, flux_limiter true),
   `v` ([0, 0]), `overrides` (none).
5. `pressure` is the total Π (§2.3.3); ε_th = (Π − Π_e − Π_n)/Σ per cell; a pressure under the cold pressure at any
   cell is refused (exit 4) naming the cell.
6. An object that covers no cell is an `SR-WARN`, not a refusal.

## Deviation from the old builder
The old `sun_disk_planes` wrote E = Σ ε_th (no ε_cold). §2.2 has E = Σ(ε_th + ε_cold) + ½Σ|u|², so the preset now
adds ε_cold. Reading (source + arithmetic, NOT PROVEN — not measured): at Σ ≈ 1, ε_cold (K₁ₑ = 21.3) is of the same
order as ε_th = 0.1|W|/M or larger, so P8 would have read ε_th = E/Σ − ε_cold below the floor and pinned the cloud near
T_floor. The timing scope (the only user) grades mechanism, not values.
