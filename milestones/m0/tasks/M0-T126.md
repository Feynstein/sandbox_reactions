# M0-T126 — the renderer's display settings (detail)

Box: linux-pc (laserax-ai), RTX 5090 physics adapter. Model claude-sonnet-5-5, level high (rung_record at launch).

## What changed
- `crates/sr-engine/src/render.rs`: `Display { glow_s, heat, density }` (`Default` = 3,000 K, [1, 10], [−6, 4]);
  `Renderer::set_display(&mut self, Display)` — S clamped to 10 K–10¹⁰ K, D's table rebuilt only when S changed, the display
  uniform (binding 10) re-uploaded each call; pub `visible_luminance` (Y), `dimming` (exact D), `dimming_table` (1,024 entries over
  log₁₀ T 3.4771…11), `dimming_lookup` (the CPU read of the table, for M0-T128's legend bar).
- `crates/sr-engine/shaders/render.wgsl`: `DisplayParams { glow, ranges, dimming[256] }`; glow.x = min(S, 3000) (yzw unused);
  b = (1 − exp(−(T/glow.x)⁴)) · D(T); heat and density maps over `ranges`. `D` is read as a + (b − a)·f so equal entries read
  exactly (all 1 at S ≤ 3,000 K).
- tests: `tests/gpu/views.rs` +4 cases (the default display; the Glow image at four settings; two Heat and two Density
  ranges; the x-bound strip); `render.rs` +3 unit cases (scope `blackbody`, 8 → 11); `verify.json` expected counts and descs.
- plants: `tests/plants/views-glow-setting-ignored.patch`, `views-colour-shift.patch` (writes S to glow.y and reads the colour at
  T·3000/S — the only plant that does).

## Measured
- `verify.py --redarm views`: 4/4 plants red (heat-linear 8, vacuum-black 7, glow-setting-ignored 2, colour-shift 2 failed).
- `verify.py --changed --task M0-T126`: GO, 57/57 scopes (logs/M0-T126.verify.log).
- Not measured: `bench`'s Glow frame_ms before and after — bench is not built (NOT RUN); the cost stays NOT PROVEN.
- The strip bound reads the cell image (`render_cells`), glow-less, as the glow is unchanged and only brightens/whitens it.
