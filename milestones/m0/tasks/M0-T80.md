## Choices where the contract is silent (cheap to reverse; keep or rule)
1. **Glow blends the formula's colours as written** — `blackbody(T_K)·b + haze·(1−b)` on the sRGB-encoded table values and the hex haze, not in linear RGB.
   §1.11 says "interpolated in linear RGB" only of the Heat/Density maps and the Element blend. If the lead wants Glow linear too, it is two decodes and an encode in `glow_colour`.
2. **No vacuum exception in Heat and Density** — §4.11 "clamp outside": a vacuum cell (Σ_floor = 10⁻⁸, T_floor) reads the Heat map's first stop (#000004, near black) and
   the Density map's first stop (#440154, dark purple). Glow is black by its own formula (haze 0, b ≈ 10⁻¹⁰) and Element has the explicit "vacuum black" (Σ < Σ_vac).
3. **A cell with Σ ≤ 0** (a state never written) reads as the floor state, so a zeroed previous state does not divide by zero.
4. **Test band** is 1 level (1/255 of the 8-bit channel) from the f64 formula; the worlds are chosen so the cold table's ~2 × 10⁻⁵ relative error cannot move T by a tenth of a level (Σ ≤ 0.25 for the T-reading views).
