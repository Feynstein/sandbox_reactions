## Changes
- `crates/sr-engine/src/dump.rs`
  - `dump_state` writes the header's `sinks` from `Step::read_sinks` (empty when the step runs no P3).
  - `load_dump` restores them through `Step::set_sinks` when the step runs P3; a dump with sinks into a step without P3 is refused, naming it. The set happens before the flux match, so the existing `dump-flux-zero` plant still applies.

- `crates/sr-engine/src/step/sinks.rs`: `Step::runs_sinks`; the module doc no longer says the dump lacks sinks.
- `crates/sr-engine/tests/gpu/dump.rs`: `a_dump_carries_two_sinks_bit_for_bit_through_the_file_and_the_load` — two sinks (one in the gas block, one in vacuum), 3 steps, dump, header lists both, file round trip, load into a fresh step, sinks bit-identical and the second dump the same bytes.
