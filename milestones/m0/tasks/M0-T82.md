# M0-T82 — Frames from headless runs

Ran on: linux-pc (laserax-ai), RTX 5090 (the physics adapter, R12), model=claude-sonnet-5-5 level=high (rung_record.py now).

## What exists
- `headless --frames-every N [--view glow|heat|element|density]` (needs `--out`): DIR/frames/f_<step>.png, step = the run's step index (as `s_<step>.bin`), at every multiple of N, the last step included, written before `--until` is read. Chunks are cut where frames fall (as `--dump-every`).
- `FrameOut` (headless.rs): a `Renderer` built on the run's State (previous = current, α = 1) with the eight anchors from `physics` and the calibration's `t_eff_sun_sb`; RGBA8 storage texture, copy to a buffer with 256-byte row padding, `png` encoder, written to `.png.tmp` and renamed. Read-back is waited for (`poll wait`) before the file is written.
- `Args.frames: Option<Frames { every, view }>` — four struct literals gained `frames: None` (calibrate.rs; calibrate_bisect.rs ×3, mechanical, as `edits` was).
- sr-engine depends on `png` (workspace entry, already approved §1.2; Cargo.lock +1 line, `--offline`).
- Scope `frames` (6 cases, tests/gpu/frames.rs), plant frames-off-by-one (red: 4 failed), testing.md row.

## Declared defaults (cheap to reverse; contract §3.3 silent)
- A run with frames needs a calibration (Sun-like T_eff anchors Glow/Heat colours): a stale or missing one is exit 6, as for a preset.
- `--view` without `--frames-every`, `--frames-every 0`, and `--frames-every` with `--cpu-reference` or without `--out` are exit 4.
- The frame at the last step is written (as the final dump).
