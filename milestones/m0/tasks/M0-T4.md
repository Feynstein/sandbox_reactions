## Declared defaults (contract silent; cheap to reverse)
- `--steps N` with `--max-steps M < N`: runs M steps, exit 2, DONE `until=unmet`, summary `until` `{"condition": "steps:N",
  "met": false}`. Reached: exit 0, DONE `until=none`, `{"condition": "steps:N", "met": true}`. `--steps 0` is bad arguments.
- No `--out`: nothing is written, stdout only. `--until` and every other §3.3 flag are unknown arguments (exit 4) until their blocks.
- `sim_time` is 0 until P1 (the time step) exists. `preset:massive` and `preset:giant` load the nominal Sun-like disk with an
  `SR-WARN` until calibration gives `preset_mass_sb`.
- `git` in summary.json: `git rev-parse --short HEAD`, else `"unknown"` (a scratch copy has no `.git`).
- Deliver says the boot is built "in a scratch copy"; read as: in the tree the script runs in — in a red-arm that is the arm's own
  copy and its own build/target; in the real tree it is the tree's own build/target (the lead's `game` binary path, §3.6).
