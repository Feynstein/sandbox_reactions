- **Scope as carried.** No one-way inflow (§0.5 [M0-D71]; the flag from M0-D71): every held–free face is the wall, item 2 stays with
  M0-D71f, and the Deliver's inflow case is not built. The disks' grid + held momentum is printed, not graded.
- **The mask.** hydro.wgsl binding 15, `texture_2d<u32>` read by `textureLoad` (`held_at`, false outside the world), bound in all
  three dispatches (step/hydro.rs `held(15, state)`), as M0-D71b's flag said. It is a sampled texture, so it uses none of the 8
  storage slots.
- **The faces.** A held side's predicted face is replaced by the free side's mirror (`mirrored`: the normal velocity and momentum
  negated) inside the face's one existing `hll`. `held_flux` then keeps the momentum only, and returns nothing for held–held faces
  and for a held cell at the world's edge. The wall is the twin's `held_wall`, with no new `hll` call: DXC inlines every call
  (M0-D118), so a separate wall `hll` would have doubled `hydro_update`'s inlined HLLs.
- **No work.** A face with a held neighbour passes φ difference 0 to `face_work`, which then returns exactly 0. A held cell returns
  before the gravity block, so it takes no work, no Σg and no radiation force.
- **The held cell.** `keep(cell)` writes its Σ, E and species bit for bit. Its next momentum planes carry what it was spared:
  −Δt·(its momentum flux differences) + Δt·Σ_mid·g, in the twin's order. `hydro_commit` adds that into `booking.held` and writes
  none of the held cell's planes, so its momentum stays as P8 left it (0). `keep` puts 0 in a held cell's momentum planes, so a
  held cell in a tile that does not move books nothing.
- **Edges.** `hydro_edges` returns at a held edge cell, so it books no escaped.
- **Booking.** `TERMS` 39 → 41: `held.spared.mom_x`, `held.spared.mom_y` (Pass::Hydro), group `booking.held` (Cells, BOOK_GROUPS 8 → 9).
  `Booking.groups` is sized `BOOK_GROUPS.len()`. step/hydro.rs looks the group up by name, because the escaped group is the first
  P4 group a writer lookup finds.
