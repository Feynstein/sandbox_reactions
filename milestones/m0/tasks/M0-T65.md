## Choices the contract left open (cheap to reverse, declared)
- **Hash framing.** §2.11 says "the canonical JSON of elements.json + reactions.json + physics.json". Taken as the canonical text of the object `{"elements":…,"physics":…,"reactions":…}`; numbers are written as their f64's shortest text, so `2`, `2.0` and `2e0` are one value. Whitespace and key order never move the hash.
- **Who needs a calibration.** A run needs one only when its scene names a preset (the time control, the observers and the app read it; the step never does, G-WATCH). A run that needs none gets `Ok(None)` even when a file is stale — `calibrate` itself must run on a stale one.
- **Validated on load beyond the schema:** K9's order (m_ign < m_ch < m_up < m_bh, m_ch < m_tov, m_tov/m_ch in [1.4, 2.0]), the presets sun < massive < giant, and c_sb > 2 × max_gas_speed — each is §2.11 item 5 / 6's exit 6.
- **`Calibration::parse` wants the complete file.** M0-T66's `--only` partial (`build/calibration.partial.json`) is not parseable by it; T66 reads partials as plain JSON.
