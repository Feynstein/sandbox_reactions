## Root cause (measured)
Reproduced first try in a scratch copy (`scratch_copy.sh`, then `check.sh ready`), every time, warm or cold. The scratch
wasm (4217871 B) differs from the real tree's (4217888 B) by one string: `srStateerrorsr-loading…` — no "ready", i.e. the
never-ready plant's code, though both trees' web.rs are identical. In a copy, tests/cargo.sh exports the shared
CARGO_TARGET_DIR (`~/.cache/sandbox-reactions/redarm-target`) and guards it with M0-D9's `cargo` function (lock + touch
the inputs); trunk runs the cargo binary itself, bypassing the function, so cargo saw the copy's preserved mtimes as
older than the never-ready arm's build and reused the plant's artifacts. Every clean web arm after a never-ready arm
served the planted wasm; a clean arm before one (try 1's Verify 3) was GO — hence « unexplained ».
