## Declared readings
- Own trackers beside Watch's: same `watch::report`, same wisp threshold (`SUN_MASS_NOMINAL`), `m_ch` from the calibration (Watch computes it
  from the physics; the shipped calibration's hash binds the two). Accessors on `Watch` would have put sr-engine in the claim (GPU scopes).
- A stage not yet held (3 frames, §1.9.3) reads `stage.cloud`, age 0 (the clock waits for a first stage).
- Pick: nearest object centre among those whose radius (≥ 3 cells) holds the clicked cell's centre; empty space leaves the selection.
- Rate: the age clock's last-wall-second rate at egui time; hidden while paused or before two instants. Frames read-back time is the last frame's egui time.
